## 📊 World Development Indicators – CO₂ Emissions Analysis

This project analyzes **CO₂ emissions data** using the World Development Indicators (WDI) dataset. The objective is to explore CO₂ emission trends, understand patterns in the data, and generate meaningful insights through data analysis and visualization.


---

## 📝 Project Overview

Climate change and global warming are strongly connected with greenhouse gas emissions. Among these, **Carbon Dioxide (CO₂)** is one of the major contributors.

In this project, the WDI CO₂ dataset is analyzed using Python and data-analysis techniques to understand:

* 🌍 CO₂ emission patterns
* 📈 Changes in emissions over time
* 🏭 Emission-related trends across countries
* 📊 Statistical patterns in the dataset
* 🔎 Relationships between different variables
* 📉 Data trends through visualizations

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze the WDI CO₂ dataset.
2. Understand the structure and characteristics of the data.
3. Perform data cleaning and preprocessing.
4. Identify trends and patterns in CO₂ emissions.
5. Create meaningful data visualizations.
6. Generate insights from the analyzed data.

---

## 📁 Dataset

The main dataset used in this project is:

**`wdi_co2.csv`**

The dataset is related to **World Development Indicators (WDI)** and contains information associated with CO₂ emissions and development-related indicators.

## 🔍 Analysis Performed

The project includes several stages of data analysis:

### 1. Data Loading

The dataset is loaded into Python using Pandas.

### 2. Data Exploration

The dataset is explored using:

* `head()`
* `tail()`
* `info()`
* `describe()`
* Shape and column analysis

### 3. Data Cleaning

The data is checked for:

* Missing values
* Duplicate records
* Incorrect or inconsistent values
* Data types

### 4. Exploratory Data Analysis

Different patterns and relationships within the dataset are explored using statistical analysis and visualizations.

### 5. Data Visualization

Charts and graphs are used to make the data easier to understand.
